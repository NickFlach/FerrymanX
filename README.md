# FerryManX

Cross-chain bridge for PFORK tokens between Ethereum and Neo X networks. Features an automated relayer service, AI-powered "Quantum Ferry" visualization with particle physics simulations, generative transaction art, and NFT minting for bridge transactions.

## Stack

- **Frontend:** React + Vite + TailwindCSS + Three.js
- **Backend:** Express + PostgreSQL + Drizzle ORM
- **Web3:** ethers.js, Hardhat, OpenZeppelin contracts
- **Bridge:** Automated relayer with cross-chain event monitoring

## Setup

```bash
npm install
npm run dev
```

See `DEPLOY_NFT_CONTRACTS.md` for contract deployment.
